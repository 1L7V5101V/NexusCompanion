## 1. 内容开关（止血，可独立发布）

- [ ] 1.1 在旁路日志的行构造处加入单一内容 gate：默认关闭，关闭时正文与模型输出字段写入类型化占位而非原文；
  三条链不感知开关。`TurnLoggerConfig` 增加开关字段但不增加内容判断分支的复制点。
  验证：真库用例——默认态写入一轮后，正文列 grep 不到原文；非内容列全部有值。
  证据：`task-1.1-content-gate.md`
- [ ] 1.2 默认态在进程启动时成立：任何持久化配置都不得使进程重启后回到开启态。
  验证：用例覆盖「曾开启 → 重启 → 回到关闭」；配置加载层断言无持久化开启值。
  证据：并入 `task-1.1-content-gate.md`
- [ ] 1.3 关闭态非内容字段完整性回归：链路归属、通道、时间戳、耗时、模型标识、三类 token 数、
  工具调用序列与状态、重试记录、错误类别在关闭态全部照常写入，且聚合口径与开启态一致。
  验证：同一聚合分别在关闭态与开启态数据上执行，断言字段集合与数值口径一致、仅正文字段不同。
  证据：`task-1.3-field-integrity.md`
