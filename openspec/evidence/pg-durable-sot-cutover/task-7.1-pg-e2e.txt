== 链路覆盖（webchat-durable-storage 全部 requirement 的集成验证）==
1. T1 接受事务提交后才 accepted（durable seq，重复注入重放原帧）；overload 预检不消耗幂等
2. loop 出站 → finisher T2（final canonical message + turn completed + pending intent + turn.completed 帧同事务）+ inbox 收束 + nexus_replay_seq 盖回
3. 通道在线帧以 durable seq 逐字下发（进程内 buffer 不参与）
4. delivery worker 认领投递 → sent + attempt；已 sent 不被二次认领（不重新生成/重投）
5. 重启模拟（组件全重建仅 DB 存续）：重发同 id 重放原 accepted 同 seq；补拉 [accepted, completed] 连续无重复；中断 turn 由启动对账收束 failed（turn.failed 帧可见）
6. REST 重建 = canonical 流（user+assistant，0-based 连续）；跨账号请求他人 chat:{tenant} → 404（tenant 由 session 派生）
